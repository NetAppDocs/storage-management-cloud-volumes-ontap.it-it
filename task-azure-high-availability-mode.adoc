= Abilita la modalità ad alta disponibilità per Cloud Volumes ONTAP in Azure
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Abilita la modalità ad alta disponibilità (HA) di Microsoft Azure per la tua coppia HA di Cloud Volumes ONTAP per ridurre i tempi di failover imprevisti e supportare NFSv4. Questa modalità può offrire un obiettivo di tempo di ripristino (RTO) di 60 secondi per i client CIFS e NFSv4 durante i failover imprevisti.

A partire da Cloud Volumes ONTAP 9.10.1, abbiamo ridotto il tempo di failover non pianificato per le coppie HA di Cloud Volumes ONTAP in esecuzione in Microsoft Azure e aggiunto il supporto per NFSv4. Per rendere disponibili questi miglioramenti in Cloud Volumes ONTAP, devi abilitare la funzionalità HA nella tua sottoscrizione Azure.

.Informazioni su questo compito
NetApp Console visualizza un messaggio quando devi abilitare questa funzionalità in una sottoscrizione Azure. Tieni presente quanto segue:

* Questa funzionalità funziona con ONTAP per ridurre il tempo di inattività delle applicazioni rilevato dai client NFS durante i failover imprevisti. Abilitarla non indica un problema con la disponibilità della tua coppia HA di Cloud Volumes ONTAP.
* L'attivazione di questa funzionalità di Azure non interrompe le coppie HA di Cloud Volumes ONTAP.
* L'attivazione di questa funzionalità nella tua sottoscrizione di Azure non influisce sulle altre macchine virtuali nel tuo ambiente né su alcun sistema a nodo singolo all'interno della stessa sottoscrizione.
* Durante i failover, Cloud Volumes ONTAP utilizza un Azure Load Balancer interno per le LIF di gestione del cluster e delle SVM che servono i client CIFS e NFS.
* Quando abiliti la modalità HA, la Console esegue una scansione del sistema ogni 12 ore per aggiornare le regole interne di Azure Load Balancer.


.Passi
Utilizza l'interfaccia a riga di comando di Azure (Azure CLI) per abilitare la funzionalità come utente Azure con privilegi _Owner_.

. https://docs.microsoft.com/en-us/azure/cloud-shell/quickstart["Accedi ad Azure Cloud Shell dal portale di Azure"^]
. Registra la funzionalità della modalità ad alta disponibilità:
+
[source, azurecli]
----
az account set -s AZURE_SUBSCRIPTION_NAME_OR_ID
az feature register --name EnableHighAvailabilityMode --namespace Microsoft.Network
az provider register -n Microsoft.Network
----
. Facoltativamente, verificare che la funzionalità sia ora registrata:
+
[source, azurecli]
----
az feature show --name EnableHighAvailabilityMode --namespace Microsoft.Network
----
+
L'interfaccia della riga di comando di Azure dovrebbe restituire un risultato simile al seguente:

+
[listing]
----
{
  "id": "/subscriptions/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/providers/Microsoft.Features/providers/Microsoft.Network/features/EnableHighAvailabilityMode",
  "name": "Microsoft.Network/EnableHighAvailabilityMode",
  "properties": {
    "state": "Registered"
  },
  "type": "Microsoft.Features/providers/features"
}
----
