= Scopri le opzioni di automazione di Cloud Volumes ONTAP
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
I team DevOps utilizzano diversi strumenti per automatizzare la configurazione e l'amministrazione dei propri ambienti di runtime del data center. Oltre a NetApp Console, puoi utilizzare diverse di queste tecnologie per l'automazione di Cloud Volumes ONTAP, incluse le API di NetApp Console, le procedure CLI di ONTAP e strumenti di automazione come Ansible e Terraform. Gli strumenti di automazione esterni si basano in genere su un'architettura Infrastructure as Code (IaC).

Usa  https://labondemand.netapp.com/["Lab on Demand"^]per esercitarti ad automatizzare Cloud Volumes ONTAP.



[[netapp-console-apis]]
== API di NetApp Console

La NetApp Console fornisce API REST che puoi utilizzare per amministrare a livello programmatico le risorse di Cloud Volumes ONTAP. Le API supportano operazioni quali la creazione e l'amministrazione di sistemi Cloud Volumes ONTAP e l'aggiunta di aggregati e volumi su Amazon Web Services (AWS), Microsoft Azure (Azure) e Google Cloud. Le chiamate API disponibili variano in base al cloud provider e al tipo di implementazione, incluse le configurazioni a nodo singolo e di alta disponibilità (HA).

Puoi utilizzare i flussi di lavoro API di Cloud Volumes ONTAP per automatizzare una tipica implementazione e la successiva amministrazione dello storage. Alcuni flussi di lavoro includono la preparazione per l'implementazione, la creazione di un sistema e l'amministrazione dello storage, con flussi di lavoro specifici per i provider AWS, Azure e Google Cloud.

[[ontap-cli]]
== ONTAP CLI

Puoi utilizzare l'ONTAP CLI per diverse attività di amministrazione di Cloud Volumes ONTAP. Le procedure e i comandi disponibili variano in base alla funzionalità e al cloud provider. Non utilizzare l'ONTAP CLI o ONTAP System Manager per aggiornare Cloud Volumes ONTAP. Esegui gli aggiornamenti da NetApp Console.

[cols="2,2,3"]
|===
| Attività | Procedure o comandi CLI | Riferimenti 


| Configura la gestione delle chiavi di crittografia per Cloud Volumes ONTAP. | Comandi AWS KMS, Azure Key Vault o Google Cloud KMS nella CLI di ONTAP  a| 
link:task-aws-key-management.html["Configura la gestione delle chiavi AWS KMS"] link:task-azure-key-vault.html["Configurare la gestione delle chiavi di Azure Key Vault"] link:task-google-key-manager.html["Configura la gestione delle chiavi KMS di Google Cloud"]



| Configura le destinazioni e i percorsi degli eventi di Event Management System (EMS). | Comandi di configurazione EMS nella ONTAP CLI | link:task-configure-ems.html["Configurare EMS"] 


| Configura un server NTP per un cluster Cloud Volumes ONTAP esistente. | `cluster time-service ntp server create` | link:task-sync-time.html["Configura i server NTP"] 


| Disabilita la compressione dei dati durante la creazione di un volume con l'efficienza dello storage disabilitata. | Comandi CLI di ONTAP per l'efficienza dei volumi  a| 
link:concept-flash-cache.html["Esamina le opzioni di efficienza dello storage"] link:reference-limitations-aws.html["Esamina il limite di efficienza dello storage AWS"]



| Crea LUN aggiuntivi. | Comandi per la creazione di LUN nella ONTAP CLI | link:task-create-volumes.html["Crea volumi e LUN aggiuntivi"] 


| Crea volumi con WORM disabilitato oppure crea copie Snapshot per i volumi SnapLock, a seconda dei casi. | Comandi di gestione di volumi e Snapshot nella ONTAP CLI  a| 
link:concept-worm.html["Gestisci lo storage WORM"] link:reference-worm-snaplock.html["Crea copie Snapshot per l'archiviazione WORM"]



| Configura il comportamento di NVFAIL per contribuire a impedire l'accesso ai dati dopo un evento di perdita di dati finché il problema non viene risolto. | Comandi di configurazione NVFAIL nella ONTAP CLI | link:concept-write-speed.html["Configura NVFAIL"] 


| Separa il traffico di replica di SnapMirror in una distribuzione Azure a nodo singolo. | Comandi CLI di rete di ONTAP e SnapMirror | link:task-segregate-snapmirror-azure.html["Separare il traffico SnapMirror in Azure"]

[[terraform]]
== Terraform

Terraform è uno strumento di orchestrazione open source che utilizza file di configurazione dichiarativi. NetApp fornisce un provider Terraform per Cloud Volumes ONTAP. Puoi usarlo per automatizzare e integrare la tua infrastruttura con IaC. Per ulteriori informazioni, consulta https://registry.terraform.io/providers/NetApp/netapp-cloudmanager/latest["provider Terraform NetApp"^].
