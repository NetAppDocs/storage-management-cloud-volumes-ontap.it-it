=== Indicazioni per aggiornare gli hotfix di ONTAP per versioni specifiche di Cloud Volumes ONTAP

ONTAP ha rilasciato i seguenti hotfix compatibili con le versioni 9.14.1, 9.15.1, 9.16.1, 9.17.1, 9.18.1 e 9.19.1 di Cloud Volumes ONTAP:

* 9.14.1P18HF1
* 9.15.1P20HF1
* 9.16.1P16HF1
* 9.17.1P11HF1
* 9.18.1P8HF1
* 9.19.1P3HF1


Per maggiori dettagli, consulta  https://security.netapp.com/advisory/ntap-20261021-0021["Avviso di sicurezza NTAP 20261021-0021"^].

Per i tuoi sistemi Cloud Volumes ONTAP, potresti ricevere una richiesta di aggiornamento a questi hotfix nella NetApp Console. Tuttavia, questi hotfix sono supportati solo quando la versione dell'agente di NetApp Console è 4.12.0 o successiva. Se la versione dell'agente di NetApp Console è precedente alla 4.12.0, ignora la richiesta.

https://docs.netapp.com/us-en/console-setup-admin/whats-new.html#console-agent-4-12-0["Console agent 4.12.0"^]
