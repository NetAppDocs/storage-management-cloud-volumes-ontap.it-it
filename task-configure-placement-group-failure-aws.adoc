= Configura le coppie HA di Cloud Volumes ONTAP per la creazione di gruppi di posizionamento in AWS
:allow-uri-read: 


[role="lead"]
Le implementazioni ad alta disponibilità (HA) di Cloud Volumes ONTAP in una singola zona di disponibilità (AZ) di AWS possono non riuscire e venire annullate se la creazione del gruppo di posizionamento non riesce. Anche la creazione del gruppo di posizionamento non riesce e l'implementazione viene annullata se il nodo Cloud Volumes ONTAP e l'istanza del mediatore non sono disponibili. Per evitarlo, puoi modificare la configurazione in modo da consentire il completamento dell'implementazione anche se la creazione del gruppo di posizionamento non riesce.

Se si ignora il processo di rollback, il processo di distribuzione Cloud Volumes ONTAP viene completato correttamente e viene notificato che la creazione del gruppo di posizionamento non è completa.

.Passi
. Utilizzare SSH per connettersi all'host dell'agente NetApp Console ed effettuare l'accesso.
. Vai a `/opt/application/netapp/cloudmanager/docker_occm/data` .
. Modificare `app.conf` modificando il valore del `rollback-on-placement-group-failure` parametro a `false` .  Il valore predefinito di questo parametro è `true` .
+
[listing]
----
{
    "occm" : {
        "aws" : {
            "rollback-on-placement-group-failure" : false
        }
    }
}
----
. Salvare il file e disconnettersi dall'agente della console.  Non è necessario riavviare l'agente Console.
